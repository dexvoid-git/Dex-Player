# About

Dex Player is a modern local music player for Android focused on simplicity, personalization, and a clean listening experience.

The app combines Material 3 Expressive, adaptive colors, and a minimalist interface designed around the user’s local music library. It is focused on offline/local playback while still offering playlists, lyrics, library management, and background playback.

---

# Features

🎵 Music Library

- Local music discovery
- Artists, Albums, and Songs
- Album artwork support
- Library organization

🎧 Player

- Play / Pause
- Previous / Next track
- Queue management
- Background playback
- Media controls

📝 Lyrics

- Online lyrics
- Offline ".lrc" support
- Local lyrics loading

📂 Playlists

- Create playlists
- Add and remove tracks
- Playlist playback

🎨 Interface

- Material 3 Expressive
- Dynamic/adaptive colors
- Dark mode
- Smooth animations
- Minimalist design

# Design Philosophy

Dex Player follows three core principles:

- Minimal — focus on the music, not the interface.
- Expressive — modern Material 3 motion and visual language.
- Adaptive — colors and surfaces adapt to the content and device.

---

# Development

Dex Player was designed and developed entirely from a mobile device.

The project explores a mobile-first Android development workflow, using Kotlin and Jetpack Compose without relying on a traditional desktop environment for the core development process.

«📱 Designed on a phone. Built from scratch.»
