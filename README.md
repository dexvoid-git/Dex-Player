🎧 About

Dex Player is a modern local music player for Android focused on simplicity, personalization and a clean listening experience.

The application combines a minimalist interface with Material 3 Expressive, adaptive colors and smooth animations to create a music player that feels native to the Android ecosystem while maintaining its own visual identity.

Dex Player is designed primarily for local music, giving users a place to manage and enjoy their own music library without unnecessary complexity.

«Designed on a phone. Built from scratch.»

📱 Built on Mobile

One of the most important parts of Dex Player isn't just the application itself.

The entire project was designed and developed from a smartphone.

From writing Kotlin code to designing the interface and testing the application, Dex Player was created using a mobile development workflow.

This project is also an experiment in how far Android development can be pushed without relying on a traditional desktop development environment.
